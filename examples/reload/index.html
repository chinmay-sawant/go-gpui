Hot reload

This paragraph lives in examples/reload/index.html, and you are previewing it here. Edit the source file and save; the open window redraws within 250 ms without a restart. The stylesheet sits in the same file, so a new background colour, font, or spacing arrives on the same poll. The counter above keeps its value across the swap, because a reload replaces the template and leaves the page state alone. A syntax error keeps the last good picture and prints one line to stderr; fix the file and the next poll draws it. The watch covers the template and an optional theme, never Go source, so a changed handler still needs a restart.
