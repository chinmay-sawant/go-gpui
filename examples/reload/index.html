Hot reload

Edit examples/reload/index.html. The window redraws within 250 ms and keeps the counter and the note.

This paragraph is here to change. Save the file with a new sentence and the open window shows it without a restart. The counter above and the text in the field stay where they were, because a reload swaps the template and leaves the page state alone. A syntax error in the file keeps the last good picture and prints one line to stderr; fix the file and the next poll draws it. The watch reads the template and an optional theme, never Go source, so a changed handler still needs a restart.
