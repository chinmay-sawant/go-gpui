Resize and repaint in ownframe v0.0.2

A window drag now relayouts once per settled size, and a click now repaints one dirty rect instead of the whole page.

Dynamic resize: MaxWidth and MaxHeight bound the window, and a drag commits one relayout per settled size.
Incremental repaint: a declared or diffed dirty rect makes the window replay only the changed box.
The frame timeline: one diagram shows which frames redraw and which only copy the buffer.
Numbers: the platform counter repaints 5 of 11 operations and skips 6; one click costs about 0.5 ms.
The examples and what to read next.

Dynamic resize

MaxWidth and MaxHeight are window bounds, not layout caps. Page.MaxSize returns them (internal/page/page_size.go:31), and Clamp pulls a size up to the minimum only (internal/page/page_size.go:37). Run hands the pair to ebiten.SetWindowSizeLimits (internal/window/run.go:53, internal/window/run.go:56), so the OS stops the window at the bound. A screen without MaxSize stays unbounded (internal/window/bounds.go:13).

A drag records the outside size in Layout and marks the window as moving (internal/window/resize.go:49). The next update commits the size in resize (internal/window/resize.go:15). A size that held still for one update commits at once. A size that keeps changing relayouts at most every 100 ms, the value of relayoutEvery (internal/window/resize.go:10). Between commits the window draws the previous frame scaled to the window (internal/window/view.go:7, internal/window/draw.go:34).

A commit calls SetSize and Redraw (internal/window/resize.go:31, internal/window/resize.go:33). syncImage then rebuilds the drawn artifact (internal/window/resize.go:40), and built skips that rebuild when the generation and the size both match (internal/window/sync.go:43). The commit ends in refreshState, which re-resolves hover and press against the new boxes at the last cursor point (internal/window/resize.go:44, internal/window/resize_state.go:7). Update runs resize before pointer, so a hit test uses the boxes of the frame being drawn (internal/window/update.go:26, internal/window/update.go:30).

if moving && time.Since(s.lastRelayout) < relayoutEvery {
    s.skipped++
    return nil
}
s.app.SetSize(wantW, wantH)
if err := s.app.Redraw(s.ctx); err != nil {
    return err
}

A relayout does not parse or cascade. Redraw executes the template and calls styledDocument (internal/page/page_draw.go:34). When the executed source is unchanged, that call reuses the cached tree and runs Cache.Relayout for the new viewport and pointer state (internal/page/page_pipeline.go:20, internal/render/cache.go:53).

The scroll offset follows the new content. syncImage calls pullScroll after every rebuild (internal/window/sync.go:19), and pullScroll clamps the offset to the content size (internal/window/scroll_clamp.go:5).

Viewport units follow the window too. TestViewportUnitsFollowTheFrame lays out 50vw at 400 px and 20vh, 20dvh, 20svh, and 20lvh at 120 px in an 800x600 frame (internal/page/page_viewport_units_test.go:8). TestVarChainReadingAViewportUnitRecomputes checks a var() chain after SetSize(400, 600) (internal/page/page_viewport_units_test.go:31).

Engine gap: @media (height) never matches

The engine media-feature parser accepts only width and inline-size names, so (height), (min-height), and (max-height) never match. TestMediaHeightFollowsTheFrame is skipped with that reason (internal/page/page_viewport_test.go:31). The gap is recorded in plans/v0.0.2/dynamic-resize.md:176 and PHASES.md:29.

Incremental repaint

A click still ends in Redraw (internal/page/page_click.go:46), but the page now reports the changed region in CSS pixels through TakeDirty (internal/page/page_dirty.go:8). A handler can declare the id it changed with Page.Invalidate (internal/page/page_invalidate.go:10). When no handler declares, Redraw diffs the previous display list against the new one (internal/page/page_draw.go:43, internal/page/page_dirty.go:34).

a.view.Count++
a.page.SetData(a.view)
a.page.Invalidate("count")

Invalidate with an empty id, or with an id that has no box, marks the whole frame (internal/page/page_invalidate.go:11). A known id marks its box, the boxes inside it, and its previous rect for the same id (internal/page/page_invalidate.go:61). growBox unions every box inside the rect, so a nested span repaints with its parent (internal/page/page_dirty_box.go:14).

diffDisplay compares the lists operation by operation (internal/page/page_dirty_diff.go:15). It unions the bounds of every changed operation and the old bounds of every removed operation. It falls back to the frame when more than maxDirtyOps operations changed, which is 8, or when the union covers more than a third of the frame (internal/page/page_dirty_diff.go:11, internal/page/page_dirty_diff.go:59).

TakeDirty pads the rect by 4 px for shadows, outlines, and antialiasing (internal/page/page_dirty_box.go:7, internal/page/page_dirty.go:24), clamps it to the frame, and clears it. ok is false when nothing changed since the previous call (internal/page/page_dirty.go:20).

The window calls TakeDirty inside drawReplayPartial (internal/window/replay_partial.go:50). planRepaint picks one of four modes: repaint one rect, repaint the whole buffer, blit the buffer unchanged, or replay the list straight to the screen (internal/window/replay_plan.go:33). A rect mode fills the sub-image with the page background and calls replay.DrawRect into the persistent buffer (internal/window/replay_buffer.go:27, internal/window/replay_buffer.go:31). A blit copies the buffer to the screen without replaying an operation (internal/window/replay_partial.go:59).

DrawRect walks Display.Order the way Draw does and skips every op whose painted box does not meet the rect (internal/replay/draw_rect.go:16, internal/replay/draw_rect.go:32). A text op carries its baseline in Y, so the box test uses the line box, and an op whose ink cannot be bounded, such as a rotated run, is always drawn (internal/replay/draw_rect.go:56). The rect is clamped to the canvas first (internal/replay/draw_rect.go:50).

These paths still repaint the whole frame. SetTheme marks the frame (internal/page/theme.go:22), and so do Load and the drawAt call behind Back and Forward (internal/page/page_nav.go:37, internal/page/page_nav.go:87). A fallback bitmap page has no display list, so it keeps the full image path (internal/page/page_draw.go:68). A rect that clamps to the whole frame becomes a buffer rebuild (internal/window/replay_plan.go:48). A page with a frame callback keeps the full replay, because a tick edits operations in place and leaves no dirty rect (internal/window/replay_partial.go:44).

The frame timeline

One update runs resize, then pointer, then syncImage, and the draw that follows reads the result (internal/window/update.go:26, internal/window/update.go:46).

A full-canvas background meets every rect, so the repainted count is not the whole story (documentation/repaint.md:75). The op filter runs at about 12 ns per op (BenchmarkDrawRectScan, documentation/repaint.md:79). One #inc click through the handler, the template execute, the relayout, and the dirty rect measures about 0.5 ms (BenchmarkClickCount in examples/platform/platform/platform_bench_test.go:12, documentation/repaint.md:81).

The examples

examples/resize shows the resize path. The page has a media query that switches the columns at 640 px (examples/resize/resize/resize.html:18), a 100vw bar (examples/resize/resize/resize.html:9), a paragraph that rewraps (examples/resize/resize/resize.html:42), and a hover control (examples/resize/resize/resize.html:34). The package opens no window itself (examples/resize/resize/resize.go:3). The default -web address is 127.0.0.1:8127 (examples/resize/main.go:18).

examples/platform shows the repaint path. The onClick handler bumps the count, calls SetData, and calls Invalidate("count") (examples/platform/platform/platform_new.go:29, examples/platform/platform/platform_new.go:36). TestClicksRepaintCountOnly clicks #inc and checks the rect stays inside #count (examples/platform/platform/platform_repaint_test.go:9). BenchmarkClickCount times the same click (examples/platform/platform/platform_bench_test.go:12). The -web address is 127.0.0.1:8115 (examples/platform/main.go:18).

The guard that keeps the two paths equal is TestRepaintMatchesFullRedraw (repaint_equality_test.go:19). It drives one interaction on two pages and compares the incremental PNG with the PNG after a full Redraw (repaint_equality_test.go:31, repaint_equality_test.go:47). The window tests pin the commit and the clamp: TestResizeCommitsOncePerSettledSize (internal/window/resize_commit_test.go:9), TestScrollClampsAfterAShrink (internal/window/resize_scroll_test.go:31), and TestMotionKeepsTheDrawnArtifact (internal/window/resize_badge_test.go:20).
